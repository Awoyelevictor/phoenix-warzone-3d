# Phoenix Warzone 3D

A lightweight, mobile-friendly Three.js autonomous battlefield spectator prototype.

## Run
Open `index.html` through a static web server (for example, GitHub Pages). Three.js is loaded from jsDelivr, so an internet connection is required.

## Prototype features
- Blue Phoenix faction vs red hostile faction
- Autonomous soldier movement, target acquisition and simulated fire
- Basic cover-seeking behavior
- Armed patrol vehicles
- Procedural low-poly battlefield props and simple hit effects
- Cinematic, overview, pause/resume and reset spectator controls
- Responsive HUD for mobile browsers

## Controls
You are the spectator. Use the HUD to pause, switch camera mode, or reset the simulation. There are no soldier movement or weapon controls.

## Current scope
This is a first playable prototype using procedural geometry and lightweight behavior logic. It is not a full commercial FPS: animations, advanced tactics, audio, pathfinding, and detailed vehicle physics are future upgrades.
